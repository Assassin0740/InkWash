## 第一章 绪论（约 8–10 页）

### 1.1 研究背景与意义
- 【写什么】NPR/风格化渲染在游戏工业的地位（水墨类先例：《大神》《墨魂》及水墨动画美学）→ 实时水墨的两大难点：**风格还原**（笔触/墨阶难以参数化）与**工程验收**（"看着像"无法回归测试）。本文价值 = 给出可量化的两条解法。
- 【证据】美术风格规范.md 的三级墨阶层级设定。

### 1.2 国内外研究/应用现状
- 【写什么】NPR 渲染技术线（cel shading → 屏幕空间描边 → NPR 光照量化）；游戏引擎中的程序化动画（IK / 程序骨骼偏移 / VFX Graph）。
- 【注意】这部分要查文献补引用，游戏作品对比挑 2–3 个有公开技术分享的写。

### 1.3 本文工作与组织结构

## 第四章 水墨风格实时渲染管线 ★核心一（约 12–15 页）

> 全章用"**逐层叠加 + 同帧 A/B 净贡献**"的实证结构组织——这是本文区别于一般毕设的 TA 方法论亮点。

- 4.1 渲染管线总览
  - 【图表】**图 4-1 管线四阶段对照图**（白模 → +量化光照 → +飞白墨线 → +宣纸底纹，四联图，数据：逐层像素差 0.150/0.035/0.020/总 0.166）
- 4.2 多阶墨量量化光照（InkCharacter）
  - 【写什么】光照量化到墨阶、色阶离散实现；2/4/8 阶对照实验（4 阶前 4 墨色覆盖 95.6% vs PBR 44.9%——S4-29~31）
  - 【图表】**图 4-2 白球量化阶数对照**（三阶 + PBR 四联）；**表 4-1**（论文-测试数据 §三 量化阶数对照表直接搬）
- 4.3 飞白墨线（InkEdge 屏幕空间 Feature）
  - 【写什么】屏幕空间边缘检测 + 飞白噪声（T_InkBrushNoise）调制线宽；大平面墨阶豁免策略（否则地板虚假笔痕）
  - 【证据】墨线宽 5px（净 3，判据 3.5–6px，同帧 A/B 关掉轮廓 = 2px）
- 4.4 宣纸底纹与墨晕（InkPaper / InkBloom）
  - 【写什么】**墨晕压暗方向与图形学 Bloom 相反**的设计（0.676→0.638，S5-43）——水墨"洇墨"审美转译成渲染参数，可作独立小节秀 TA 思维
- 4.5 墨彩回填与净贡献（_ChromaKeep）
  - 【写什么】保色相不改明暗的彩度保留；同帧 A/B 净贡献 0.043/0.036（判据 ≥0.03）
- 4.6 墨特效系统：溅墨/墨花/刀光（InkSplash/InkSlash + 对象池）
  - 【证据】S5-46~52：溅墨 24 次、墨花随落速缩放 ×1.6、**池 40 丢弃 0**（对象池有效性）
- 4.7 实时调参面板（InkStylePanel）与风格验收指标
  - 【写什么】把"画面风格"变成可回归的数值判据（分离度 0.586≥0.30 / 墨线 3–6px / 彩度净贡献 ≥0.03）——**本节是全文 TA 方法论的代表段，写透**

## 第五章 程序化动画与特效系统 ★核心二（约 12–15 页）

> 24 节长链没有动画资产 → 全程序驱动，这是第二个差异化亮点。按"一条蛇形驱动器统管全部姿态"的架构叙事。

- 5.1 脊柱链拉直与姿态基准
  - 【写什么】FBX 原生骨架 → 24 节单链拉直（Awake 一次）、restPose 基准采样（_restRel）；头锁定数学 `R_i = R_{i-1} · headExtra · lRel_i`；**头部对齐终值人眼在回路定稿**（F9 调参面板 → pitch=-55.5）——顺带写"机器反解三轮失败"的教训作为工程方法论（骨轴/质心/图像伺服皆被须骨稀释，视觉问题必须图像证据兜底）
  - 【图表】**图 5-1 头对齐前后对照**（Tools/screenshots/_head3_before_28b.png / _head3_after_side.png / _head3_after_top.png）
- 5.2 蛇形脊柱驱动器（ApplySerpentineSpine）
  - 【写什么】正弦行波沿弧长参数 u 传播：中心线 `SerpPoint(u)` → 逐节切线 → `FromToRotation` 写骨骼旋转；相位全游戏单节拍器 SerpPhase() ⇒ 姿态切换零跳变；驱动器扩展参数（extraPitch 沿 u 包络实现俯冲/吐息整身俯仰）
  - 【图表】**图 5-2 蛇形行波示意图**（自绘：中心线 + 相位箭头 + 切向逐节标注）；**图 5-3 四招式同驱动器对照**（盘旋/俯冲/扫尾/吐息录屏抽帧，m7_dragon/*.mp4 已有素材）
- 5.3 姿态低通混合与航向限速
  - 【写什么】动作衔接指数趋近 BlendPose（6/s）；航向硬限速 LimitHeading（110°/s，构造上杜绝锐角瞬转）——"动作连贯性"从调参问题变成**架构约束**，好写
- 5.4 指骨卷曲程序化（ApplyFingerCurl）
  - 【写什么】60 根指骨自动采集（叶骨→第一分叉点）、静态扣握 + 深度梯度 + 随主行波开合；绝对写入无累积
  - 【图表】**图 5-4 爪部卷曲特写**（_v29_fingers2.png）
- 5.5 主角侧程序化细节（对比章节，证明方法泛化）
  - 【写什么】古剑挂点程序化求解、挥砍刀锋拖尾速度门控（起速 15.0 m/s ≥ 阈值，S2-17）、FootIK 贴地（落脚 -0.000m，S2 姿态专项 1–2）、握拳度补丁（攻击帧 1.55 vs 摊手 2.2）
- 5.6 特效层集成：风暴吐息（DragonStormVfx）与接口假空防护
  - 【写什么】接口引用 != null 探测不到原生销毁的 Unity 经典陷阱 → `(_src as UnityEngine.Object)==null` 归正 + OnDestroy Shut 双保险——放工程可靠性小节
