# 跨机克隆复原清单

> 换电脑、拉新克隆、队友接手 —— 先看这一份。
> 配套自检脚本：`Tools/check_clone_deps.py`

## 0. 一句话

**git 仓库里没有任何素材文件。** 全新克隆 = 一份代码 + 一堆悬空 GUID。
换机器要额外做三件事：**拷素材 → 清 QFramework 残留 → 跑自检**。

---

## 1. 为什么素材不在仓库里

不是漏提交，是 `.gitignore` 故意的。两条理由：

1. **授权** —— QAL v1.0「禁止再分发素材本身」、Unity 商店标准 EULA「不可再分发」、
   PrimeTween「禁止把源码放进项目分发」。**入库 = 借 git 再分发 = 违约**，公开仓库尤其。
2. **体积** —— 720 MB 二进制，且是可重新下载的只读素材，版本控制零收益。

| 被排除的路径 | 内容 | 体积 | 复原方式 |
|---|---|---|---|
| `/Assets/ThirdParty/` | Quaternius / KayKit / Ziyuan / Kenney / KevinIglesias / QFramework | 647 MB | 整目录拷贝 |
| `/Assets/Char_Feng/` | **主角模型**「武侠风格角色-锋」 | 12 MB | 整目录拷贝 ／ `Tools/install_feng.py` |
| `/Assets/W_Sword/` | **主角兵器**「古代宝剑」 | 60 MB | 整目录拷贝 ／ `Tools/install_w_sword.py` |
| `/Assets/QFrameworkData/` | CodeGenKit 生成目录 | 小 | Unity 自动重新生成 |
| `/Assets/_Project/Audio/**/BGM/*.mp3` | BGM | 小 | 整目录拷贝 ／ 重新下载 |
| `/_RawDownloads/` | 上游 glTF 源（Blender 转换用） | 大 | 仅重跑 `gltf2fbx_scaled.py` 时才需要 |

---

## 2. ★★ 一条铁律：`.meta` 必须一起拷

`Assets/ThirdParty/` 下有 **2039 个 `.meta`**，它们**一个都没进 git**。

`.meta` 是 GUID 的载体。prefab / 场景 / 材质里所有引用都长这样：

```yaml
m_Mesh: {fileID: 7238157132297919992, guid: c68a78a74a299104a8f51cee5029c146, type: 3}
```

- ✅ **连 `.meta` 一起拷** → GUID 原样保留 → prefab 即插即用
- ❌ **只拷 `.fbx`、让 Unity 自己重新导入** → Unity **重新生成 GUID** →
  全部引用**静默断裂**（不报错，只是模型/贴图/动作凭空消失）→ 等于白拷

**目录级 `.meta` 也要带**：`Assets/ThirdParty.meta`、`Assets/Char_Feng.meta`、`Assets/W_Sword.meta`。

## 3. 操作步骤

### 3.1 目标机器先克隆仓库

```bash
git clone https://github.com/Assassin0740/InkWash.git
```

### 3.2 ★ 先清掉脚本装的 QFramework（若之前装过）

如果目标机器上曾跑过 `Tools/install_qframework.py`，那份 QFramework 的 `.meta` 是
**Unity 当场生成的新 GUID**，与源机器的 GUID 体系**不一致**。直接覆盖会造成两套 GUID 混杂，
引用了 QFramework 组件的 prefab 会断。

```powershell
Remove-Item -Recurse -Force "Assets\ThirdParty", "Assets\QFrameworkData"
Remove-Item -Force "Assets\ThirdParty.meta", "Assets\QFrameworkData.meta"
```

> `Assets/QFrameworkData/` 不用拷 —— 让 Unity 的 CodeGenKit 自己重新生成。

### 3.3 整目录拷贝（在**源机器**上执行）

假设目标工程根是 `E:\Unity Project\InkWash`：

```powershell
$SRC = "D:\Unity Project\InkWash\Assets"
$DST = "E:\Unity Project\InkWash\Assets"

robocopy $SRC $DST ThirdParty ThirdParty.meta Char_Feng Char_Feng.meta W_Sword W_Sword.meta /E /R:1 /W:1 /NFL /NDL
```

`/E` 含空目录，`.meta` 因为是普通文件会被一并带上。

### 3.4 BGM

```powershell
robocopy "D:\Unity Project\InkWash\Assets\_Project\Audio" "E:\Unity Project\InkWash\Assets\_Project\Audio" /E /R:1 /W:1 /NFL /NDL
```

（`Audio/` 下大部分文件本就在 git 里，重复拷只是覆盖同名文件，无副作用。）

### 3.5 让 Unity 导入并编译

切回 Unity 窗口点一下，等右下角**编译进度条走完**。

- 首次导入 3700+ 个文件需要几分钟，属正常。
- 若停在 **Safe Mode** 询问弹窗，点 **Exit Safe Mode**。

### 3.6 自检

```bash
python Tools/check_clone_deps.py
```

期望输出：

```
[A] 不入库素材目录       全部 [OK]
[B] BGM                 找到 1 个 BGM 文件
[D] 结论                通过 —— 工程资产的全部外部引用都能在磁盘上找到定义
```

**只要 `[D]` 不是「通过」，就还没拷全**，按脚本给的 4 条常见原因排查。

### 3.7 编译仍报错时

```powershell
# 清掉增量编译缓存后让 Unity 重来
Remove-Item -Recurse -Force "Library\ScriptAssemblies"
```

回 Unity 触发 `refresh`。

## 4. 已知陷阱

| 现象 | 真因 |
|---|---|
| prefab 打开是空的 / 模型白色方块 | 漏拷 `.meta`，GUID 被 Unity 重新生成 |
| `CS0246: 'QFramework' 找不到` | `Assets/ThirdParty/QFramework/` 缺失 → 跑 `Tools/install_qframework.py` 或整目录拷 |
| Unity 进 **Safe Mode** + bridge 连不上 | 有编译错误就会进安全模式；`Temp/.com-unity-codely.json` 不会生成。**先修编译再谈自动化** |
| 模型有了但没贴图 | 拷了 `.fbx` 没拷它引用的**外部** `.png`（Ziyuan 的贴图在 `textures/` 子目录） |
| 敌人不动 | `Assets/ThirdParty/KayKit/Animations/Rig_Medium/*.fbx` 缺失 —— 3 个 `Enemy*.controller` 仍引用它 |
| 克隆下来没声音 | BGM 的 `.mp3` 被 ignore |

## 5. 附：最小必需集（不想全量拷时）

用 `Tools/tmp/dep_min.py` 扫 guid 引用闭包得出：**真正被入库资产引用的只有 36 个文件 / 169.7 MB**。

| 组 | 文件数 | 体积 | 必要性 |
|---|---|---|---|
| Ziyuan（墨龙 + 3 怪 + 3 张贴图） | 8 | ≈44 MB | 必需 |
| Quaternius UAL2 / UAL（主角攻击动画） | 2 | ≈43 MB | 必需 |
| Char_Feng（`Feng.fbx` + 贴图 + 10 个 `.anim`） | 12 | ≈10 MB | 必需 |
| W_Sword（FBX + base + normal） | 3 | ≈55 MB | 必需 |
| KayKit（`Rogue_Hooded` + `Rig_Medium/Large` + 3 骷髅） | 11 | ≈16 MB | ⚠️ 已退役，仅 3 个 `Enemy*.controller` 仍引用 |

⚠️ 这是**当前引用的快照**：一旦要换模型、加敌人、用新的 Quaternius 包，就会缺。
**想省心就全量拷。**
