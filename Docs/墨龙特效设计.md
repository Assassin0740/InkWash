## 四、实现形态（沿用项目既有手法）

**驱动层与渲染层分开**：

```
EnemyDragon  ──调用静态入口──▶  DragonStormVfx（场景单例）
                                  ├─ 强度状态机（目标条数/烟浓度 + 平滑逼近）
                                  ├─ 电弧渲染器（A 与 B′ 共用）
                                  └─ 黑烟渲染器（B）
```

- **场景单例 + 静态入口**，形状与 `Assets/_Project/Scripts/Effects/InkHitVfx.cs` 一致：
  受击方不需要认识特效实现，只调一个静态方法；全场共用一个池、一份材质。
- **惰性池**：首次真正需要时才建，不在 `Awake` 里建（否则编辑期 `AddComponent` 就往场景塞对象）。
- **不产生 GC**：池满时静默丢弃并计数，不扩容。
- **表现层不得带崩玩法链路**：入口不抛异常、不阻塞；池/材质拿不到时**只警告一次**。
- **入口要自愈**（坑表 二-5）：被禁用的 `MonoBehaviour` 不执行 `Update()` ⇒ 静态入口里
  `if (!enabled) enabled = true;`。

### 需要给 `EnemyDragon` 补的接口

现在只暴露了 `GetHeadPosition()` / `GetTailPosition()`，**取不到沿链的发射点**。需要补：

```csharp
public int SpineCount => _spine.Count;
public Vector3 GetSpinePosition(int i);        // i 小 = 尾/根侧（沿用既有方向约定）
public Vector3 GetSpineDirection(int i);       // 用于电弧沿身体主轴的走向
```

## 五、材质与颜色规约

**★ 本项目 Linear 色彩空间下，`Material.SetColor` 不做 sRGB→Linear 转换 ⇒ 必须按线性值给**
（这条在朱砂描边上已经踩过一次）。

| 用途 | 线性值 | 对应 sRGB | 说明 |
|---|---|---|---|
| 电弧芯（hot core） | `(1.0, 1.0, 1.0)` | `#FFFFFF` | 最亮的一根，占宽度 ~30% |
| 电弧辉光（outer） | `(0.55, 0.86, 1.0)` | `#C4EFFF` | **青白**，主视觉 |
| 电弧 HDR 乘子 | 1.6 ~ 2.4（随强度） | — | 只有开 HDR/Bloom 时才读得出"电"的白热 |
| 黑烟 | `(0.020, 0.021, 0.025)` | 近墨黑 | 与 `InkHitVfx.inkColor (0.055,0.062,0.082)` 同族、更深 |
| 烟中电弧 | 辉光 × 0.55 亮度 | — | 比主体电弧暗，读作"藏在烟里" |

**层级关系**：青白是冷色、墨黑是无彩 ⇒ 与龙身的**赭墨暖褐**（`_ChromaKeep 0.10`）形成冷暖分离，
不会和朱砂描边 `(0.48,0.035,0.022)` 抢读。**浓淡轴不单独承担区分**（坑表经验）⇒ 靠冷暖 + 亮度。

### 已知风险（下载后第一件事就是验证）

1. **`Zap VFX` 的兼容性说法自相矛盾**：商店页兼容表**明确列出 `2022.3.0f1` → URP 兼容**
   （还有 `2021.3.0f1 / 2023.1.0f1 / 6000.0.23f1`），但发布者自己页面的文案写着
   「only available for Unity 2023 onwards」，第三方镜像站也抄的是「2023.1.0+」。
   ⇒ 导入后**先验 shader 能不能编**（`ShaderUtil.GetShaderMessages` 必须 0 条），
   不行就**只取它的贴图**，材质换挂项目自己的 URP Shader。
2. **黑烟包是 legacy shader**：官方明说「material is created with legacy shader so you'll have no
   problem with different render pipelines」—— 这是"不挑管线"，但在 URP 下 legacy 粒子材质
   仍可能显示成洋红 ⇒ 一样是**只取贴图**最稳。
3. 两包的**描边/墨色**都不受项目 `InkCharacter.shader` 管 ⇒ 特效是"加在墨色之上的光"
   （宣纸上的电光），不走墨阶量化。这是刻意的：电弧该是"亮"的，量化会把白热压成灰。

## 七、验收判据

| # | 判据 | 合格线 |
|---|---|---|
| 1 | 常态稳态活跃电弧条数 | **2 ~ 3** |
| 2 | 俯冲/扑咬段活跃电弧条数 | **8 ~ 10** |
| 3 | 黑烟发射点覆盖的链节数（俯冲段） | **= 24**（头尾都要有） |
| 4 | 时刻上**烟里有电弧** | 俯冲段至少 80% 的采样帧内，存在"与烟团距离 < 0.6 m 的电弧" |
| 5 | 帧时间不劣化 | 开/关特效对比，战斗场景平均帧时间增幅 ≤ 0.5 ms，且 0 帧 > 16.7 ms |
| 6 | 身长保险丝（姿态没被特效带歪） | 7.3 ~ 8.1 m（沿用第十四轮口径） |
| 7 | GC | 稳态 0 B/帧 |
| 8 | 人眼 | **录视频**交用户判形态与节奏 |

> 统计口径沿用第十五轮：**按相位分组**，度量窗口裁到事件边界；
> 断言不许写死期望值（从被测配置推导）；保险丝用**墙钟**不用帧数。
