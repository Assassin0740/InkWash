## 一、毕业论文选题及选题内容（工作内容）

### 选题

**《基于 Unity 框架的 3D 水墨动作游戏全流程设计与实现》**

以"中国水墨画的实时渲染还原"为核心命题，用 Unity 引擎从零完成一款 3D 第三人称水墨动作游戏（项目代号 **墨刃 · InkWash**），覆盖**渲染管线 → 玩法系统 → 内容生产 → 测试优化 → 项目交付**的完整工程链路，并给出可量化的画面风格验收指标。

### 工作内容（六个部分）

**1）水墨风格实时渲染管线 ★ 论文核心**

- 自研 URP 水墨着色器 `InkCharacter.shader`：多阶光照量化（墨阶）、飞白轮廓（屏幕空间线宽）、宣纸底纹
- 墨色系统：墨彩回填（保色相、不改明暗）、主体墨阶塌缩、彩度保留系数 `_ChromaKeep`
- 大平面的墨阶豁免策略（否则地板/墙面出现虚假笔痕）
- 墨晕扩散、水墨粒子等风格化特效

**2）角色与动作战斗系统**

- 第三人称角色控制器：移动 / 转向 / 冲刺 / 相机跟随
- 战斗动作：轻攻击三段连击（第三段带前冲）、蓄力重击、闪避翻滚（含无敌帧）、技能位
- 动画状态机与手感：动画拓扑设计、后摇取消、连招输入缓冲、过渡打断规则
- 武器与姿态：古剑挂点程序化求解（握点 / 握拳度补丁）、FootIK 贴地

**3）敌人 AI 与关卡组织**

- 三类敌人的行为设计（近战追击 / 远程投掷 / 精英横扫）
- **墨龙 BOSS**：24 节骨骼链驱动的空中循环巡游、四段招式（盘旋 / 撕咬 / 扫尾 / 吐息）、三阶段数值
- NavMesh 寻路 + 波次生成器 + 战斗场地

**4）Roguelike 局内成长循环**

- 单局流程：主菜单 → 清房间 → 三选一技能 → 精英 → BOSS → 结算
- 技能池以 ScriptableObject 定义，升级时加权随机三选一

**5）测试、性能与优化**

- 自建自动化验收体系（累计 208 项断言 = 主用例 198 + 专项 10），每轮改动可回归
- 建立**量化验收指标**（而非"看着像不像"）：墨量分离度、轮廓像素宽度、墨彩净贡献、帧率
- Profiler 基线分析与对象池优化

**6）工程化与项目管理**

- 按 PMP 知识体系 + Scrum 敏捷（1 天 = 1 个 Sprint，共 7 个 Sprint）编排实施计划、Backlog 与故事点
- 第三方素材的**授权合规**处理（CC0 / 商店 EULA 差异下的版本控制策略与复原脚本）
- 自建 AI 远程驱动 Unity 的施工协作管线（TCP Bridge），把人工投入压缩到"决策 / 账号 / 验收"三类不可替代动作
