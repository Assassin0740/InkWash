## A. 动画 / 龙 / 战斗

- **换模型 = 换骨架**：换 `avatar`；容器 `localScale` = 目标身高 ÷ 原生身高、`localPosition.y` 重定；`stateOffsets` 整表重测｜`FootIK` 竖直偏移只能走**容器 `localPosition.y`**｜**骨数必须等于 `mesh.bindposes` 数**｜重建/回退 prefab 用 `InstantiatePrefab`+`ApplyPrefabInstance`（**不要 `LoadPrefabContents`**）；拓扑 `Idle/Walk/Run/Dash` + `Atk1→Rec→Atk2→Rec→Atk3`，转移**按列表顺序求值、先满足者胜**（带 Trigger 的必须排在移动阈值之前），过渡期只认 `GetNextAnimatorStateInfo`
- **`PlayerController` 注入输入是「相机相对」的**：喂世界方向会歪 ~55° ⇒ 剑砍空气。正解 `Vector2(Dot(dir,right), Dot(dir,fwd))`
- **墨龙**：`TickChase` 覆写成盘旋（`TickCircling`）；攻击 `Tell(0.35)→Dive(0.45)→Strike(0.22)→Recover(0.58)`；高度**只由 `_currentLift` 一处真相**写进容器 `localPosition.y`

## B. 墨色系统（`InkCharacter.shader` / `InkStylePanel`）

- **墨彩回填** `color *= 1 + (albedoHue − luma)·_ChromaKeep·2.2`（只改色相不改明暗）；**`2.2` 为主角近黑贴图标定 ⇒ 套到高饱和贴图过曝成彩虹**（龙 0.45→**0.10**）
- **`_BandBias` 负太多 ⇒ 暗部塌进焦墨、连颜色一起失掉**；抬过头 ⇒ 发白。**浓淡轴不能单独承担层级区分**，优先用**冷暖**。现状：主角 **+0.15** 淡墨／六敌人 **0.00**／墨龙 **−0.34** 浓墨
- **线粗细是「屏幕」属性** ⇒ `px ≈ 300×宽度 + 1.6`：主角 **0.012（5 px）**／剑 0.009／敌人 0.018／龙 0.018／高台 0.026｜**敌人描边 = 朱砂红线性 `(0.48,0.035,0.022)`**；`Material.SetColor` 在 Linear 空间**不做 sRGB→Linear 转换** ⇒ 必须给**线性值**
- **`_HueKeep`**：明度守恒色相注入 `color = luma(墨阶色) × albedo/luma(albedo)`。**默认 0 = 旧行为逐像素一致** —— shader **全场共用**（主角/龙/剑/场景）⇒ 新增参数必须默认零影响。现状：六敌人 **1.0**／主角·龙·剑 **0.00**
- 大平面**不许**走墨阶量化（`steps<0.5` 必须 `saturate(x)`）；墙/地/台/檐/道具 `_Bands=1`｜**龙**：`_BaseMap` 清空、`_ChromaKeep 0.10`、`_InkDensity 0.25`、`_Bands 4`、赭墨暖褐

- **单位极乱**（×124.69 ~ ×0.0024）⇒ Blender 侧归一 + Unity 侧按**顶点真值**微调，别跨工具对账。`Z_Enemy_MoLong` Generic 9.000 m／50 552 面｜`Z_Orge` 2.600／17 309｜`Z_Orc` 2.050／21 590｜`Z_Undead` 1.949／16 743｜`Z_Dragon_LP` 6.999／6 157｜**`mixamorig:`/`Bip001` 可自动 Humanoid**；**蛇形龙不能 Humanoid**（报 `'Head' not found`）⇒ Generic + 程序驱动｜**龙无 body albedo，颜色画在 glTF `emissiveTexture`**；骨名 `drgon_0xx`、2 Mesh `Object_281/282`、`bindposes=273`
- **可见性度量的正确口径**：**`Showcase.unity` + 演示场相机** + **同 tick 背靠背差分帧**（渲染器开/关逐像素差，两帧都关投影），**不用哨兵底色**。两条保险：**在视锥内**（`TestPlanesAABB` + 报相机坐标）、**同批放阳性对照**。工具 `dg_sc_verify.cs`★／`ev_verify.cs`／`ev_scan.cs`／`ev_tune2.cs`。**⛔ 绝不用洋红**
- **定标脚本的相机必须每帧重设**（演示场脚本会在 `Update` 里拉回去）｜**`mesh.vertices` 在本工程返回空数组** ⇒ 读顶点真值不可用；`renderer.bounds = localBounds × lossyScale` 是推的
