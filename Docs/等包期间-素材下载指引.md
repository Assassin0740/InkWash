## 0. 先记住一句话

**下的是「骨骼 + 动画」，不是「贴图」。**

水墨风格会让所有材质被我们自己的 Shader 覆盖，所以第三方模型的原贴图质量、PBR 质感**基本白给**。你只需要它：

- 有**骨骼（Rigged）**
- 自带**动画剪辑（Animated）**
- 形状结构干净、多边形数别太高（低多边形优先）

→ **别下高写实 PBR 模型**，那是在给水墨 Shader 添麻烦。

## 1. 三个站点的实际情况（已核实）

| 站点 | 授权 | 要登录吗 | 直接下载 | 备注 |
|---|---|---|---|---|
| **Kenney** | CC0（官网明确：public domain，可商用，无需署名） | ❌ 不要 | ✅ 每包一个 ZIP | 最省事，先从这里开始 |
| **Quaternius** | ⚠️ **逐包不同**（见下方警告） | ❌ 不要 | ✅ | 低多边形动画角色/怪物主力 |
| **Mixamo** | 免费商用（Adobe 账号，不可再分发模型本身） | ✅ **要 Adobe 账号** | 站点内应用到模型 | 动画库最大，主角动画靠它 |
| Poly Haven | CC0 | ❌ | ✅ | HDRI / 贴图，本项目**可选** |
| ambientCG | CC0 | ❌ | ✅ | PBR 贴图，水墨风**基本不需要** |
| freesound | CC0 / CC-BY / BY-NC | ✅ | ✅ | **注意避开 BY-NC**（禁商用） |
| Google Fonts | SIL OFL | ❌ | ✅ | 书法字体 |

> ### ⚠️ 警告：Quaternius 各包授权**不统一**，不能一概说「CC0」
>
> 该站官网 FAQ 仍写着 "All models are under the CC0 License"，但**实际随包附带的授权文件才是准的**。
> 本次下载的三个包实测结果：
>
> | 包 | 随包授权文件写的 | 能否写进论文说「CC0」 |
> |---|---|---|
> | Universal Animation Library 2 | **CC0 1.0 Universal** | ✅ 可以 |
> | Modular Character Outfits - Fantasy | **CC0 1.0 Universal** | ✅ 可以 |
> | Bestiary - Dungeon Monsters | **Quaternius Asset License (QAL) v1.0**（2026-08-28 更新） | ❌ **不能**，须写 QAL v1.0 |
>
> QAL v1.0 摘要：可免费用于个人/教育/商业项目，**无需署名**；但**不得把素材本身再分发**
> （不能再打包成素材包/模板/库存文件分发，无论是否修改过）。
> 它第 7 条明确「旧版授权对已获得的素材继续有效」—— 即授权按**下载时该包所附版本**为准。
>
> **对毕设的影响**：游戏里用完全没问题（教育/商业都允许，还不用署名）。
> 但 **`Assets/ThirdParty/` 已加入 `.gitignore`** —— 否则仓库一旦公开就等于「再分发素材」，踩到 QAL 第 3(a) 条。
> 授权凭证已另存 `Docs/素材授权/`（受 git 跟踪），论文附录直接引用。
>
> **结论：Quaternius 每个包都要打开它自己的 `License*.txt` 看一遍**，别信官网 FAQ，也别跨包推断。

## 3. 下完放哪儿

**第三方整包 → `Assets/ThirdParty/<作者>/<包名>/`，内部结构一个字都别动。**

| 素材 | 放置目录 | 理由 |
|---|---|---|
| 第三方模型 / 动画 / 贴图（整包） | `Assets/ThirdParty/<作者>/<包名>/` | 保住包内相对结构，贴图才绑得上 |
| 自制模型 / 材质 / 特效 | `Assets/_Project/Art/…` | 这是我们自己的产物 |
| 书法字体、自选 UI 图 | `Assets/_Project/Art/Fonts/`、`Art/UI/` | 会随项目一起版本控制 |
| 音效（第三方原包） | `Assets/ThirdParty/Kenney/…` | 同上，整包保留 |
| 授权文件 / 预览图 | 随包保留 + 另存 `Docs/素材授权/` | 论文附录要引用，且需受 git 跟踪 |

**新增第三方包后，直接跑整理脚本，不用手工搬：**

```
"C:\Users\廖中钰\.workbuddy\binaries\python\versions\3.13.12\python.exe" Tools\organize_thirdparty.py
```

默认空转只打印计划，确认无误后加 `--apply` 实执行。脚本会：
1. 把 Unity 用不到的格式（`.glb`/`.gltf`/`.blend`/Unreal 法线）移到 `_RawDownloads/`（**不删除**）
2. 整包移动到 `Assets/ThirdParty/`
3. 复制授权文件到 `Docs/素材授权/`
4. 移动文件时**连同 `.meta` 一起搬**，保住 GUID

> **两条硬约束**
> - Unity **不会**自动解压 ZIP。解压到临时目录，再把包文件夹拖进来。
> - 包文件夹**先别放进 Assets**。直接放进 `Assets/Ziyuan/` 或任意临时目录 → 跑脚本归位 → 脚本负责移出那些会让 Unity 报错的格式。
>   （.blend 文件一进 Assets 就会触发 `Blender could not be found` 报错，就是你刚才 Console 里看到的那条。）
