# 素材来源与授权清单

> 用途：毕设论文"素材来源"章节备查 + 规避版权风险。
> 规则：**优先级 CC0 > CC-BY > 站内授权 > 不明来源（不用）**。
> 每下载一项素材，在下方表格新增一行。

---

## 授权类型速查

| 授权 | 能否商用 | 是否需署名 | 风险 |
|---|---|---|---|
| **CC0**（公共领域） | ✅ | ❌ 不需要 | 无 |
| **CC-BY** | ✅ | ✅ **必须署名** | 低（署名即可） |
| **SIL OFL**（字体常用） | ✅ | 保留授权文件 | 低 |
| **Pixabay Content License**（Pixabay 音乐/图片） | ✅ | ❌ 不需要 | **低：不得以独立文件形式再分发**。注意：它**不等于 CC0**，论文附录须写全称 |
| Adobe 免费账号（Mixamo） | ✅ 项目可用 | 建议注明来源 | 中（受 Adobe 条款约束） |
| **QAL v1.0**（Quaternius 2026 新包） | ✅ 个人/教育/商用全免费 | ❌ 不需要 | **低：唯一限制是不得把素材本身再分发**（不得打包转卖或当素材库发布）。已用 `.gitignore` 屏蔽 `Assets/ThirdParty/` |
| 站内授权（爱给网等） | 视具体条目 | 视具体条目 | 中（**逐条核对**） |
| 来源不明 | ❌ | — | **高（禁用）** |

> ### ⚠️ CC-BY 的署名是强制义务（第 16~20 项）
>
> 这 5 个 Sketchfab 素材都是 **CC-BY-4.0**：可商用，但**必须署名作者**。这是本工程目前
> **唯一一批有署名义务的素材**（其余是 CC0 或"不得再分发但免署名"）。
>
> - **上游 glTF 源不入库**（160 MB，被 `/Assets/ThirdParty/` 规则连带排除），
>   但 **license.txt 副本已归档** `Docs/素材授权/Sketchfab__Ziyuan__*__license.txt`（该目录入库）
> - **论文 / 演示 / 答辩材料里凡是出现这 5 个素材，都要贴署名串**。
>   格式（照抄 license.txt 原文即可）：
>   ```
>   This work is based on "Chinese dragon" (https://sketchfab.com/3d-models/chinese-dragon-a5ad5ec06f43461f95bb93e95fe7553b)
>   by MAXDESIGN-3D (https://sketchfab.com/MAXDESIGN) licensed under CC-BY-4.0
>   ```
>   （另 4 个把标题/链接/作者名换成各自 license.txt 里的即可）
> - 复原方式：`Tools/gltf2fbx_scaled.py`（Blender 批量 glTF→FBX + 单位归一 + 清 Sketchfab 垃圾几何）
>
> **技术备注**（毕设可当实现点写）：这批素材单位极度混乱，归一系数从 **×124.69 到 ×0.0024**
> （差 5 万倍），且 Sketchfab 打包会附带 `Icosphere` 环境球与"地面阴影板"垃圾几何。

> **为什么换 KayKit 当主角**：原方案是 Quaternius 模型 + UAL1/UAL2 动画 + Kevin Iglesias 跑步片段，
> 三套来源靠 Unity Humanoid 重定向黏合，反复出现"走路仰身""跑步扭腰/滑步"。
> KayKit 的**模型与动画是同一套 Rig_Medium 骨架**（32–35 骨），动作直接对得上，不存在跨源重定向偏差。
> 模型和动画均 CC0，可商用。
> ⚠️ itch.io 在部分网络下不可达，故经 GitHub 镜像仓库获取（镜像只做搬运，授权不变）。

> ### ⚠️ 一个必须写清楚的缺口：**本工程没有任何建筑 / 地图素材**
>
> 2026-09-15 全库清点结论（用户问"不是有素材吗，有地图素材吗"时逐包核对）：
>
> | 素材包 | 实际内容 |
> |---|---|
> | Kenney（RPG Audio / UI Audio / Impact Sounds） | **全是音效**，零模型 |
> | KayKit（Adventurers / Animations / Skeletons） | 角色 / 动画 / 骷髅敌人 |
> | Quaternius（UniversalBaseCharacters / UltimateMonsters / UAL1 / UAL2） | 角色 / 敌人 / 动画 |
> | Quaternius `StylizedNatureMegaKit` | **68 个树石草木**（唯一的场景类素材） |
>
> 所以关卡里的院墙、石门、地面、高台**全部是程序化白盒 Cube**，**不是"忘了换模型"**。
>
> **替代路径**（不新增任何外部依赖）：
>
> - **8 条瓦檐**（白盒 Cube + `M_Ink_Eave`）：`Eave_N/S/E/W` @ y=4.16、`EaveGate_N/S/E/W` @ y=2.94
>   —— 中式院墙的关键识别特征就是檐口那道**水平线**
> - **20 个自然道具**：取自 `StylizedNatureMegaKit`，放在内外墙之间的环带（|x| 或 |z| ∈ 11~20）
>
> ```bash
> # 复原（编辑态脚本，走 Codely 桥）
> python Tools/exec_cs.py cs/g_props.cs      # 建瓦檐 + 实例化道具 + 归一化尺寸/对齐地面
> python Tools/exec_cs.py cs/g_props2.cs     # 写整个 sharedMaterials 数组形成 prefab override
> python Tools/exec_cs.py cs/g_props3.cs     # 按索引重排 + 重命名 Prop{NN}_{标签}_{原名}
> ```
>
> **两个坑**：编辑态脚本末尾调 `AssetDatabase.Refresh()` 会**重导 fbx ⇒ prefab 重载 ⇒ 实例的材质 override 丢失**；
> 按**名字**匹配重排道具会让两个同名 `Pine_1` 叠在一起（必须**按索引**）。
