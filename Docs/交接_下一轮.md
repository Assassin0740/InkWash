## 2. 现在做到哪了（第十八轮，已提交 `07248dd`）

用户上一轮给了四条反馈：**头歪没顺脖子 / 爪子该往后（要往前飞）/ 尾巴末端翘该保水平线 / 动画该不断重复**。

**★ 定案：前三条都不是波形造成的，而是模型「基准姿态」自带的。**
做法是造一个"纯基准帧"——`swimWaveAmp = 0`（曲线横向值恒 0 ⇒ `FromToRotation` 恒单位四元数 ⇒ 脊骨回到原生姿态）＋ `limbSwingDeg = 0`，与正常驱动**同机位**对照，两组数字**逐位相同**：

```
尾尖绝对抬升 Δy                       = +0.265 m（中段累计 +0.799 m）
头扇 26 枚叶子骨均值方向 vs 颈段方向     = 52.43°
四条腿首段 dot(容器 fwd)               = 0.490 / 0.283 / 0.099 / −0.351
```

真因：`StraightenSpineBase()` **只拉直脊柱链本身**，头簇（挂 `_spine[22]`）与尾巴（挂 `_spine[0]`）是挂在脊柱节点上的**刚性分支**，相对姿态从没被校正过。

**上一轮判错在口径**：判"尾巴水平 ✅"量的是「分支末端相对根节的 y **极差**」——刚性分支极差**恒 0** ⇒ 判 ✅，而**绝对值**一直翘着 +0.265 m。**「量波动」≠「量位置」**（坑表 24）。

### 修法与验收

| 部位 | 新增字段（已写入 prefab） | 验收值 | 改前 |
|---|---|---|---|
| 头 | `headAlignPitchDeg 30`／`headAlignYawDeg 0`／`headAlignRollDeg 0`／`headAlignLinks 2` | 只转末尾 2 节 ⇒ 头整块绕颈根转、脖子不动 | 头扇偏离颈轴 52° |
| 尾 | `tailLevel true`／`tailWaveAmp 0.35`／`tailWaveSpan 0.5`／`tailPhaseLagDeg 0` | 逐节 max\|pitch\| **0.00°**；尾尖 Δy **0.000 m**；尾尖横摆 **0.686 m** | −6°→−33°；Δy +0.265 m |
| 腿 | `limbSweepBackDeg 60` | dot(fwd) **全负**（−0.79/−0.32/−0.80/−0.10）；首段方向变化 **38~78°** | 前三条为正 |
| 循环 | — | 整周期残差 **1e-5 m** vs 相邻帧 2.7e-2 m ⇒ 严格周期 | — |

关键实现点：
- 头对齐只转 `_spine[Count-2]`（`Count-1` 是无几何的链尾骨），且用**整旋转** `extra * q`——只转目标方向的话 `FromToRotation` 是最小旋转，**绕骨轴的 roll 不受控**，头会"转过去了但扭着"。
- 头角度是**量出来的**：对头簇 50 枚骨（排除 `_limbRoots` 全子树）做 **PCA 第一主轴**，俯仰 30.21°（展布 0.864 m / 垂直半径 0.359 m / 扁平度 2.41 ⇒ 长轴可信）。
  ⚠️ **不要**用"叶子骨均值方向"——那 26 枚是颅顶/鬃根，朝上朝前，照着做会把头**往下压 52°**，与要的正好相反。
- 尾巴从"刚性分支"升级成**可驱动链** `_tailChain`（13 节，主轴链每层取「与上一段方向夹角最小」的子节点；**不能取「离根最远」**，会拐上横向短鳍）。
- 四肢后掠必须**限幅** `Mathf.Clamp(..., ±limbSweepBackDeg)`，否则裸符号旋转会把 `drgon_0175` 的 x 翻号、腿甩过身体中线。
- **两条驱动路径必须行为一致**：`ApplySpineOffsetsRaw`（旧/攻击相位）与 `ApplySerpentineSpine`（巡游）都做了头/尾校正，否则相位一进一出头会"啪"地弹一下。
- `EndHover()` 要一起复位尾巴（新增 `_tailBaseLocalRot` 表），否则留一个扭曲姿态，下次起飞第一帧会看见它"弹"回基准。

## 4. 硬规矩（动手前扫一遍，别重踩）

**最贵四条**
1. `EnemyBase.CanSeePlayer()` 是"地面怪"心智 ⇒ **Boss 必须覆写 `TickIdle`/`TickChase`**。
2. `InkStylePanel.Broadcast()` 遍历 ALL entries ⇒ **材质面板必须按源材质分族**。
3. **不要用「骨骼局部轴」做几何约定** ⇒ 一律用**容器语义轴**（绕容器 `up` = 左右，绕 `right` = 俯仰）。
4. **一个阈值被两个身份不同的对象共用，迟早出事**（第十七轮就栽在这：19 条旁挂链只有 4 条是腿）。

**第十八轮新增四条（坑表 24~27）**
- **问"平不平"量绝对值，问"动不动"量极差** —— 刚性分支极差恒 0，会给假 ✅。"摆幅"要量**末端**，`amp·u` 包络下量全链均值会被压掉一大半。
- **姿态不对，先做「基准姿态 vs 驱动姿态」同机位对照** —— 波幅打 0 即得纯基准帧。两组数字相同 ⇒ **别再调波形**，直接做姿态校正。成本几分钟，比调参快一个量级。
- **长链骨架上的"附件"（头簇/尾巴）必须单独对齐** —— 拉直脊柱不会改变它们的相对姿态。
- **按帧数取样的统计必须钉 `Time.captureFramerate`** —— 不钉的话 `yield return null` 的步长跟随编辑器帧率，60 帧可能只覆盖周期零头 ⇒ **全是假阴性**。另外：划水轴与后掠轴垂直时 `Quaternion.Angle(基准, 当前)` 对划水**接近盲的**（58° 后掠 + ±25° 划水，合成总转角只从 58° 变到 62.6°）。

**四个静默杀手**
- ① Tooltip 里的 `\n" +` 会被工具链变成真换行 ⇒ `CS1010`/`CS1003`；探针字符串里嵌未转义双引号同理。
- ② **`Edit` 并行编辑同一个文件会静默丢改动** ⇒ 批量改走一次性 Python 脚本 + `count(old)` 断言。
- ③ `--runtime` 跑完不退 Play ⇒ **改资产前先 `stop`**。
- ④ 改了 `.cs` 后运行时可能仍读旧值 ⇒ 编译判据分三层（DLL 内容 ≠ 内存程序集 ≠ 回读字段值）。

**静默失效**（不报错、Console 干净，最危险）
- 引用被写坏时判据必须 `TryGetGUIDAndLocalFileIdentifier` **命中**才算过。
- 改 C# 默认值不生效；**只改 prefab 也会让源码默认值腐烂**（双向，用 `check_prefab_overrides.py` 查）。
- 改 `.mat`/`.shader`/`.asset` 后必须 `refresh`；**HLSL 错误不进 Console**，要用 `ShaderUtil.GetShaderMessages` 确认 0 条；新增 uniform 须 4 个 `UnityPerMaterial` CBUFFER 同序同类型。
- **被禁用的 MonoBehaviour 不执行 `Update()`** ⇒ 入口要自愈。
- `Shader.Find` 失败静默退 `URP/Unlit`；`NavMeshAgent` 建不起来静默自由落体（演示场至今未烤 NavMesh，`Failed to create agent` 刷屏）。

**验收纪律**
- 断言**不许写死期望值**，要从被测配置推导；保险丝用**墙钟**不用帧数。
- **量之前先怀疑尺子**。度量窗口裁到事件边界（首帧有启动瞬态）。对照帧必须**同 tick 背靠背** `Camera.Render()`。
- **⛔ 绝不用洋红做可见性底色**（会污染判读）。
- `SerializedObject` dump 数组必须 `NextVisible(true)`。
- 域重载会把当前场景换成空场景 ⇒ 探针前先跑 `Tools/cs/q_open_scene.cs`；`OpenScene` 在 Play 下会抛异常。

**git**
- 两机交替提交**一律 `merge`，不要 `rebase`**。
- 沙箱代理会拦 github ⇒ `env -u http_proxy -u https_proxy git push`。
- 对象库判据 = `git count-objects -v` 的 `in-pack: 0`。
- **累计 9 个提交未 push**（`ddb751d` `7b955b2` `1ba3b30` `5350d9b` `44d9935` `70b9893` `07248dd` …）—— 需要用户先开代理。
