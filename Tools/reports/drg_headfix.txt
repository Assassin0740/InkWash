★ 读法：
  · 「总偏差」= 该帧头载体相对 rest(FBX) 帧被拧了多少度 ⇒ **0 = 与模型师傅摆的一模一样**。
  · old = `headLockUseRestPose: 0`（锁拉直后的 _baseRel，第二十五轮行为）。
  · new = `headLockUseRestPose: 1`（锁拉直前的 _restRel，本轮修法）。
  · 「头簇局部旋转自检」= 抽样的叶子骨局部旋转与 rest 帧的最大夹角；
    必须 ≈ 0 ⇒ 证明头是**刚性**的、「挂点姿态 = 头姿态」成立。
  · **new+pitch0 = 新锁 + headAlignPitchDeg=0 ⇒ 应为 0.00°**（完全回到 FBX 原生姿态）。
  · **头簇相对挂点 Δdir / Δrot**：逐叶比「相对挂点的方向」与朝向（对应用户口述判据），与渲染/相机全无关。
    ★ Δdir 是**归一化方向角**：均匀缩放不改变方向 ⇒ 两个实例 scale 不同也能比。
    ★ 头簇是刚性不驱动分支 ⇒ Δdir / Δrot 在**每一行**都必须 =0（含 rest 行）；
      它证明的是「锁定没有把头的形状拧变形」，**不是**分辨档位的判据 —— 分辨力在「总偏差」列。
  · **半径比** = |叶骨-挂点| 活体 / 基准（均值）。第一版这里报的是「Δpos 0.1935m」，
    恒定出现在**包括 rest 在内**的每一行 ⇒ 那是跨实例标尺差，不是姿态误差。
    ★ 来源已由 drg_scale26.cs 实测钉死：`Z_Enemy_MoLong.prefab` 根 localScale = 1.0000
      （骨骼 lossy 0.0024），`Z_Dragon.prefab` 根 localScale = 0.7546（骨骼 lossy 0.0018）
      ⇒ 1 / 0.7546 = **1.3252**，与上表半径比逐位相同。纯均匀缩放，与姿态无关；
      0.1935 m 也由此对上：0.1935 / 0.3252 = 0.595 m = 叶骨到挂点的平均距离。
  · rest 档只有一行（它与相位无关，本来就不该随相位变）。
