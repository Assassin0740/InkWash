## ★ 关于「紫色」：那不是材质丢失

目录里很多图是**紫色/洋红底**，那是探针给相机铺的**哨兵底色**（`Camera.backgroundColor`），
只在 Play 里临时设置，**不写进任何资产、不改任何 prefab/材质**。你没看到的紫色 = 我铺的画布。

**但这批紫色图已废弃**，原因是选色失败：

| 哨兵色 | 能否使用 | 原因 |
|---|---|---|
| 洋红 `(255,0,255)` | ❌ **禁用** | **正是 Unity「材质丢失」时渲染的颜色** —— 看图的人在视觉上无法区分「我的画布」与「真的缺材质」。我自己就据此误判过一轮（曾断言"MoShan 渲染成品红 = 缺材质"，被 `dg_enemy_far` 证伪） |
| 绿 `(0,255,0)` | ❌ 禁用 | 8-bit RT 抖动最大 62（`(44,240,44)`）> 阈值 24 ⇒ **凭空多出 25% 假"非背景"像素** |
| **纯蓝 `(0,0,255)`** | ✅ 推荐 | 单通道抖动 ≤21，且与洋红明显不同 |
| **纯红 `(255,0,0)`** | ✅ 可用 | 同上（用于「换底色对照」） |

**已换色**：`dg_pixel_hist` / `dg_enemy_probe2` / `dg_enemy_cull` / `dg_enemy_shots`
/ `dg_enemy_diag` / `dg_enemy_wide` 六支探针的哨兵色已统一改为纯蓝/纯红。
**因此本目录里带 `_magenta` / `_green` 后缀的图都是旧口径，只当反例。**

**多一个白拿的判据**：**换底色后读数不变的那部分才是真画出来的东西。**
MoGu 的 `RGB(12,9,8)` 共 **37671** 个像素，蓝底与红底下**一个不差**；
而 MoShan 在两种底下的量化色都只有 2 种，且**全是底色自身的抖动值**。
